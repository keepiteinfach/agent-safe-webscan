# Roadmap

## 0.2
- Baseline/diff mode for regression detection.
- GitHub Action that uploads SARIF to code scanning.
- More precise CSP parser and cookie classification.
- Signed rule metadata and rule-pack versioning.

## 0.3
- Optional OSV enrichment for confidently fingerprinted client-side packages.
- Streamable HTTP MCP transport with authentication and rate limits.
- Reproducible fixtures for WordPress, Next.js, Astro and common reverse proxies.

## Research track
- Agent-facing content provenance hints.
- More robust hidden prompt-injection heuristics without forwarding untrusted text to models.
- Confidence calibration using curated benign/unsafe fixtures.
